 trabalho--Faculdade-TRIANGULO-PASCAL-123628

 Descrição:
 
Este projeto implementa o Triângulo de Pascal
utilizando a linguagem de programação C.
O programa solicita ao usuário a quantidade de
linhas desejada e exibe o triângulo na tela.

 Funcionalidades:
 
 Solicita a quantidade de linhas.
 Calcula os valores do triângulo.
 Exibe o resultado organizado no terminal.
 Valida a entrada e aceita de 1 a 30 linhas.

 Tecnologias:
 
 Linguagem C
 Biblioteca stdio.h
